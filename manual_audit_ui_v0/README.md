# UI screenshot manual audit package

This package contains all 100 UI screenshots from the expanded pilot: 50 real and 50 generated images. The folder names and blind CSV do not reveal the labels.

## What to open

1. Read `RATING_GUIDE.md`.
2. Open `blind_review.csv` in a spreadsheet.
3. Review every image in `overlays/` using the `local_overlay_path` column.
4. Fill the six rating columns and `reviewer_notes`.
5. Keep `answer_key.csv` closed until all 100 reviews are complete.

The matching original images are in `images/` if an overlay is hard to interpret. The red polygons in an overlay are detector output. The first pass is a quality screen; it is not yet exact ground-truth annotation.

After the screen, select 20–30 representative or difficult images for manually drawn quadrilateral ground-truth boxes. Store that future annotation as a separate versioned artifact.

The package was generated by `make_category_audit_package.py` from the expanded TextRich manifest and `detector_pilot_expanded_gpu_v0` overlays.
